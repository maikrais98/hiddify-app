# U3 client — активные действия

- [ ] Получить разрешённую отдельную ветку feat/luma-u3-account-debug на Mac в соседнюю worktree по docs/u3-client/MAC.md; исходную рабочую ветку не переключать.
- [ ] На Mac выполнить Xcode build, проверить подходящие отдельные Debug signing profiles и подписанные entitlements; не регистрировать новые Apple identifiers автоматически.
- [ ] Проверить на физическом iPhone Keychain при перезапуске/блокировке, доверие сертификату, закрытый маршрут через Mac, logout и revoke. Пользователь согласовал эти native проверки на своём Mac вместо отсутствующего здесь Xcode.

Локальная реализация и автоматические проверки завершены, результаты в docs/u3-client/history.md. Пользователь разрешил публикацию отдельной feature-ветки; main/merge/release не разрешены. Native iOS проверки остаются обязательным Mac gate; до них не заявлять готовность приложения на iPhone.
