# Разработка Luma

Luma — личный некоммерческий проект для себя, семьи и друзей. Небольшие исправления и понятные отчёты об ошибках приветствуются. Перед большой доработкой лучше обсудить её с автором: проект развивается в свободное время.

## Обратная связь

Укажите устройство, ОС, версию сборки, шаги воспроизведения и ожидаемый результат. Для ошибок Luma обращайтесь к автору этого форка. Контакты команды Hiddify относятся к исходному проекту.

Не прикладывайте приватные ссылки подписок, QR-коды, конфигурации и данные доступа. Для диагностики можно использовать [безопасную сводку](docs/safe-diagnostics.md), предварительно просмотрев её содержимое.

## Подготовка исходников

Требования к Dart и Flutter указаны в [pubspec.yaml](pubspec.yaml), параметры зависимостей — в [dependencies.properties](dependencies.properties). В проекте есть нативный код и подмодуль ядра; одного `flutter pub get` недостаточно для полной сборки.

```sh
git clone --recurse-submodules https://github.com/maikrais98/hiddify-app.git
cd hiddify-app
flutter pub get
make gen
make translate
```

Для уже клонированного репозитория подмодуль можно подготовить командой `git submodule update --init --recursive`.

Платформенные зависимости и команды подготовки описаны в [Makefile](Makefile): например, `make ios-prepare` или `make android-prepare`. Сборка iOS требует macOS, Xcode и CocoaPods; установка на устройство также требует соответствующей подписи и VPN-возможностей. Параметры подписи и выпуска нельзя заимствовать у Hiddify.

## Проверка изменений

Запускайте проверки, которые относятся к изменению. Для Flutter-кода после подготовки зависимостей:

```sh
flutter analyze
flutter test
```

Нативные проверки и проверки релизного процесса находятся в [test/](test/) и [scripts/](scripts/). Команды выше не заменяют проверку VPN на устройстве и не подтверждают готовность к выпуску.

Держите изменения небольшими, описывайте результат и выполненные проверки. Не включайте токены, закрытые профили, сертификаты и локальные настройки подписи в коммиты.

Luma — форк [Hiddify](https://github.com/hiddify/hiddify-app). Внутренние имена Hiddify и прежнее имя Woman in Red местами сохранены для совместимости и истории. Переименование проекта на GitHub само по себе не меняет идентификаторы установленных приложений.

Исходная [лицензия Hiddify Extended GPLv3](LICENSE.md) сохраняется. Перед распространением сборок учитывайте [заметки о лицензии](docs/gpl-compliance.md). Код, который исправляет общую проблему Hiddify, можно отдельно предложить исходному проекту.
