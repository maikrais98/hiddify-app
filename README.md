# Luma

Личный прокси-клиент для себя и друзей.

## О проекте

Luma — приложение, которое я развиваю для собственного удобства, семьи и друзей. Здесь я учусь, экспериментирую с интерфейсом и дорабатываю привычные сценарии подключения. Продажи и коммерческое развитие не планируются.

В основе — открытый исходный код Hiddify и его прокси-ядро. Luma остаётся публичным форком с собственной подачей и доработками.

## Что можно делать

- Добавлять профили по ссылке, QR-коду или из файла.
- Подключаться через импортированный профиль, выбирать сервер и проверять задержку.
- Смотреть доступную информацию о трафике и сроке действия профиля.
- Настраивать маршрутизацию и пользоваться безопасной диагностической сводкой.

Приложение использует уже выданный доступ: для подключения нужен собственный профиль или ссылка от администратора.

## Текущий статус

Основной фокус — **iOS**, интерфейс и тестовые сборки для небольшого круга пользователей. В репозитории также остаётся код Android, macOS, Windows и Linux, унаследованный от Hiddify; наличие кода не означает готовый и проверенный релиз Luma для каждой платформы.

Тестовая установка согласуется с автором проекта. Ссылки на магазины и сборки Hiddify не являются загрузками Luma.

## Что изменено относительно Hiddify

- **13 июля 2026:** начата самостоятельная визуальная версия под именем Woman in Red — иконка, цвета и пользовательские идентификаторы приложения.
- **Июль — ноябрь 2026:** доработаны iOS-интерфейс, сценарии подключения, выбор серверов, настройки, безопасная диагностика и процесс проверки тестовых сборок. История изменений доступна в [коммитах](https://github.com/maikrais98/hiddify-app/commits/main/).
- **11 ноября 2026:** публичное название проекта — **Luma**; обновлено оформление репозитория под личный некоммерческий проект.

В коде и старых документах ещё встречаются Woman in Red и Hiddify. Часть внутренних имён сохранена для совместимости; они не обозначают отдельные приложения Luma.
