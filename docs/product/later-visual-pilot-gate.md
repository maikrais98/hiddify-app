# Light theme, map, and presets pilot gate

Status: prepared; **deferred until pilot data**. Card Later-visual must remain `Not Started` until demand is observed.

| Idea | Demand signal | Experiment | Money proxy | GO | ITERATE | STOP |
|---|---|---|---|---|---|---|
| Light theme | Users explicitly fail or churn because a light appearance is unavailable | Prototype preference in a pilot cohort; measure activation and support separately by choice | Support minutes caused by appearance plus retained paid contribution | Clear demand and no worse activation/support | Demand exists but readability or support regresses | Preference only, no behavior or support effect |
| Server map | Users cannot choose or recover a working server from the list | Compare list-only with an optional map on the same server set | Time-to-working-session and support minutes per server-selection incident | Faster working session with no extra errors or support | Faster for one segment only | Novelty clicks without better outcomes |
| Task presets | Repeated routing tasks require expert support | Offer a small, reversible preset for one observed task | Avoided support hours minus implementation/maintenance cost | Repeated JTBD, positive net support saving, safe rollback | Useful but unclear labels or scope | No repeated JTBD or higher configuration failures |

Every result needs build/version, cohort denominator, observation period, activation definition, retention window, support denominator, and maintenance owner. Report money as observed cost or contribution; keep estimates and forecasts separate.

No production redesign starts from this document. The next step after the iPhone reliability gate is a pilot with the privacy-safe measurement contract in `docs/analytics/baseline.md`.
