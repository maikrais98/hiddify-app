# Historical luma documentation archive

Prepared 2026-11-07 from local KVN materials. This is a reference archive of October 2026 design, diagnostics and QA45 release evidence, not a new verification of TestFlight status or device behavior. Original source files were not modified.

## Coverage

- Text documents from `docs/`, retaining their relative paths.
- Markdown and JSON release evidence from `luma-qa45-testflight`.
- Markdown and JSON reports from QA45 foreground performance, video performance and limit display.
- Target/device inventories, raw logs and display-observation records are not included.

## Privacy and limitations

All links were removed conservatively, including public links. Source commit hashes and test conclusions remain where possible. Home-directory paths were converted to repository-relative paths or neutral placeholders. Screenshots from docs are excluded because they may contain account details or access-bearing QR codes. Their relative paths are recorded in `PRIVATE-ONLY-MANIFEST.json`; this manifest contains no image data.

`SANITIZATION-REPORT.json` records replacement categories and counts by file without original values. These historical records describe their original dates; successful preparation of this archive does not validate the original release claims anew.
