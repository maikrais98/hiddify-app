# Главная Luma: инвентаризация для отдельного home.html

Проверено 25.10.2026 по `/workspace/user/Documents/KVN/blizzard-aurora-optimization`. Приложение не изменялось. В этой рабочей копии вложенных AGENTS.md не найдено; действуют инструкции пользователя. Это сверка исходников, не новый запуск приложения. SVG-сияние из существующего прототипа можно перенести как фон, сохранив нижеприведённую композицию. Браузерное стекло остаётся визуальной имитацией.

## Композиция сверху вниз

| Область | Содержимое и действие | Геометрия исходника |
|---|---|---|

| Hero | Статус по центру, затем задержка; кнопка питания в отдельной позиции; подпись под ней. | Ширина min(доступная,353), высота 336 при обычном тексте. Слот статуса 98; кнопка 148×148, радиус 44. ## Точные русские состояния

| Состояние | Заголовок hero | Подпись действия | Доступность кнопки |
|---|---|---|---|
| Disconnected | «Нажмите для подключения» | «Подключить» | Доступна |
| Connecting | «Подключение...» | «Подключение...» | Недоступна |
| Connected | «VPN подключён» | «Отключить» | Доступна |
| Disconnecting | «Отключение...» | «Отключение...» | Недоступна |
| Connected + требуется применение изменений | «Переподключить» | «Переподключить» | Доступна |
| AsyncError | Пустая строка в текущем выражении | «Подключить» | Доступна |

Не заменять отключённый статус придуманным «VPN выключен». Для iOS Connected не переводится обратно в «Подключение...» только из-за отсутствующего ping. При отсутствии профиля нажатие подключения вызывает сообщение о профиле и добавление профиля; не изображать успешное реальное VPN-подключение в HTML. Демонстрационные переходы обозначить вне телефонного интерфейса.

Задержка при готовом измерении выглядит как **«Задержка 42 мс»** — двоеточие удаляется именно для Blizzard; число 42 допустимо только как явно демонстрационное. Состояния iOS: «Обновление…», «Неизвестно», «Тайм-аут», «Непредвиденная ошибка»; во время проверки — skeleton, accessibility-label «Задержка: тестирование...». Нажатие обновляет измерение; во время обновления/проверки недоступно. Padding области: 16 слева/справа, 2 сверху, 22 снизу; скругление 24.

Условная подпись WARP: «Защищено с помощью WARP» со щитом только при соответствующем режиме и валидном измерении; не включать её в обычный демонстрационный сценарий автоматически.

Карточка профиля: `${расход / объём} · осталось ${N} дней`; при сроке больше 365 дней «осталось ∞ дней», при истечении «Истек», при исчерпании «Квота исчерпана». Для главной нет полосы прогресса расхода. Данные сервера, профиля, подписки и версия — динамические, не копировать личные значения. У remote-профиля дополнительная кнопка на главной обновляет профиль (не следует автоматически изображать меню с троеточием — см. реализацию `ProfileActionButton`).

## Карта исходников

Все пути ниже относительно проверенной рабочей копии:

- `lib/features/home/widget/home_page.dart`: AppBar, порядок элементов, отступы, условная карточка профиля, бейдж версии.
- `lib/features/home/widget/connection_button.dart`: status/action labels, правила доступности, callback подключения, `_BlizzardConnectionHero` и геометрия.
- `lib/features/connection/model/connection_status.dart`: отображение Disconnected/Connecting/Connected/Disconnecting.
- `lib/core/theme/blizzard_tokens.dart`: размеры hero, кнопки и dock; радиусы.
- `lib/features/proxy/active/active_proxy_card.dart`: наличие серверной карточки только при Connected, переходы, размеры. При отсутствии данных сервера на iOS — запасная кнопка с `pages.proxies.title`.
- `lib/features/proxy/active/ios_active_proxy_delay_indicator.dart`: состояния задержки, обновление, размеры области взаимодействия.
- `lib/features/profile/widget/profile_tile.dart`: название профиля, условная подписка, дополнительные действия, переход в profiles.
- `lib/core/router/adaptive_layout/my_adaptive_layout.dart`: две мобильные вкладки.
- `lib/core/router/adaptive_layout/blizzard_dock.dart`: нативная и веб-геометрия dock.
- `lib/core/model/constants.dart`: актуальное название `luma`.
- `assets/translations/ru.i18n.json`: проверенные русские строки.

## Рекомендация для отдельного прототипа

Основной вид — Connected с подписью «VPN подключён», демонстрационной задержкой, кнопкой питания, подписью «Отключить», сервером и профилем. Отдельный переключатель вне экрана телефона может показывать Disconnected/Connecting/Connected: не добавлять новый продуктовый контрол внутрь главной. Сохранить существующий SVG-фон сияния, тёмные спокойные content-карточки и прозрачные функциональные поверхности. Ссылку «Настройки» направить на существующий index.html; не менять сам экран настроек в рамках этой работы.
