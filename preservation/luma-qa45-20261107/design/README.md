# luma / Blizzard design preservation package

Public-safe preservation copy prepared 2026-11-07. Original project paths are retained below this directory. Includes design specifications, tokens, mapping, source structures, HTML/CSS/JS prototypes, shaders, and reviewed design assets from design/, design-assets/, design-exports/, design-handoff/, and the 2026-10-27 Figwright transfer.

All text was scanned locally. Personal home paths were replaced with /workspace/user. Potential personal identifiers, email addresses, IP addresses, device identifiers, credentials, and unverified external URLs were replaced with [REDACTED]. JSON parsing was checked after changes. Public documentation URLs were retained. Original files were not modified.

Apple Vision OCR failed in this environment. All images were then checked locally with Tesseract OCR. CoreImage QR detection failed to detect visible QR codes in a previewed contact sheet and was not trusted. Therefore only SF Symbol raster assets with clean OCR were retained; other raster images were conservatively excluded rather than edited. No binary payloads were embedded in retained text. OCR cannot establish perfect absence of private information. This is a curated design archive, not a complete runtime snapshot or a guarantee of pixel parity. Some original references target omitted images or local source paths; no replacement assets were fabricated.

SANITIZATION-REPORT.json lists included paths, sizes, SHA-256 checksums and redaction categories/counts without original values. The private exclusion manifest remains outside this public package. Dependencies, logs and caches were omitted.
