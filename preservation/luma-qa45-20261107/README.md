## Точные оригиналы и приложение

В непубличном черновике GitHub Release `luma-qa45-preservation-20261107` сохраняются:

1. `luma-QA-0.1.0-45-local.zip` — существовавшее локальное приложение luma QA 0.1.0 (45).
2. `luma-QA-0.1.0-45-source-snapshot.zip` — точный локальный QA-снимок: 1404 файла релизного дерева и 116 дополнительных файлов генерации и окружения.
3. `luma-original-materials-20261107.zip` — 2691 неизменённый файл материалов и проверочных списков, включая изображения, исключённые из публичной копии.

Черновик предназначен для участников репозитория с правом записи. Его нельзя публиковать без отдельной проверки оригинальных данных: архив приложения содержит provisioning profile и может содержать встроенные параметры диагностики.

ZIP-файлы проверены чтением содержимого и сравнением SHA256 с исходниками. У приложения сохранены исходные байты подписи; текущее доверие локальному сертификату не подтверждено (`CSSMERR_TP_NOT_TRUSTED` у исходника и распакованной копии). Это архив существующего QA-приложения, не новый установочный файл TestFlight45 и не подтверждение возможности установки сегодня.
